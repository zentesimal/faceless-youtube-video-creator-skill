# <Channel name>: YouTube Studio settings

**Example.** First-run setup writes your own copy to `channel/youtube-settings.md`, filled from your answers. It's everything to paste into YouTube Studio once per channel. The images sit next to it in `channel/`.

## 1. Customization › Branding

| Field           | File                    | YouTube's spec                                                               |
| --------------- | ----------------------- | ---------------------------------------------------------------------------- |
| Picture         | `channel/avatar.png`    | 800×800 PNG, shown as a circle (keep the subject inside the middle circle)   |
| Banner image    | `channel/banner.png`    | 2560×1440; text and logo inside the centred 1235×338 area every device shows |
| Video watermark | `channel/watermark.png` | 150×150 PNG; Display time: "Entire video" (it becomes a subscribe button)    |

Leave a row empty if you don't have the file yet: Studio keeps the default.

## 2. Customization › Basic info

**Name:** <Channel name>

**Handle:** @<handle>

**Description** (≤ 1,000 characters; the first two lines show in search):


**Links:** your site (the first link shows on the banner).

**Contact info:** a public email (optional).

## 3. Settings › Channel › Basic info

**Country of residence:** where you or your company are registered (it sets payouts and taxes).

**Keywords** (one line; quote phrases):

```
"<main topic>" <tool> <tool> "<how-to phrase>" "<problem phrase>" <audience word>
```

## 4. Settings › Channel › Advanced settings

**Audience:** "No, set this channel as not made for kids" (unless it is).

## 5. Settings › Upload defaults

**Description** (the footer every video gets; the skill adds it to `youtube.md` too, from `channel.md`):

```
<footer from channel.md>
```

**Tags:** 5–8 words from your topic sheet's main keywords.

| Field                 | Value                                              |
| --------------------- | -------------------------------------------------- |
| Category              | Science & Technology (or Education)                |
| Video language        | your channel's language                            |
| Title and description | same                                               |
| License               | Standard YouTube License                           |
| Comments              | On; hold potentially inappropriate ones for review |

**Altered or synthetic content:** answer per video when uploading. An AI voice reading slides usually doesn't need the label; realistic generated people, places or events do. Check YouTube's current help page before your first upload.

# YouTube UI assets (for the Subscribe slide)

- `youtube-icon.svg`: the YouTube play-button icon (red `#FF0000` rounded rectangle, white triangle), used as in YouTube's brand guidelines: unmodified, next to a call to subscribe to our channel. Don't recolour, stretch or animate it.
- `Roboto-400.woff2`, `Roboto-500.woff2`: Roboto (Apache-2.0, via Fontsource), the typeface of YouTube's UI, so the channel row and the Subscribe pill read as the real thing.
- The bell, thumbs-up/down and cursor are drawn inline in `../slide.html` (Material-style paths).

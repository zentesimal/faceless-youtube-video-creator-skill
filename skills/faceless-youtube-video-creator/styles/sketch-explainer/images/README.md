# Reference frames (local only)

Drop the frames that define this look here (screenshots you took), then run:

```bash
node "${CLAUDE_SKILL_DIR}/scripts/moodboard.mjs" "${CLAUDE_SKILL_DIR}/styles/sketch-explainer/images" --out "${CLAUDE_SKILL_DIR}/styles/sketch-explainer"
```

Everything in this folder except this README is gitignored: the frames are someone else's work, used as a style reference only. They never go into a video, a thumbnail or `$W/assets/`.
